# Agent 接入：文字传输版

用平台的「Agent 自定义接入」把正文当原生文字推给眼镜。和页图版是两个 Skill、两个云端实例，并存使用。不接大模型，不回答小说内容，语音只认固定说法。

这个版本在 `agent` 分支上，不合并进 main。

## 怎么启动

平台创建 Agent 插件时自动生成同名 Skill，靠插件名和描述召回。两个 Skill 绑在同一副眼镜上时，靠说法区分：

| 说法 | 进入 |
|---|---|
| 看小说、继续看小说 | 眼镜看小说（页图版） |
| 打开文字阅读器、文字阅读器、用文字版看小说 | 文字阅读器（本版） |

插件名称：`文字阅读器`。

插件描述：

> 用千问 AI 眼镜的原生文字看 TXT 小说，镜腿翻页立即响应，支持自动翻页、字号、粗细和亮度调节。只在用户明确说“打开文字阅读器”“文字阅读器”“用文字版看小说”时使用。用户只说“看小说”“继续看小说”时不要使用，那是「眼镜看小说」技能的入口。

## 工作方式

```
眼镜 reader-text 页面 ◄── SHOW_UI（文字）── 平台 ◄── WebSocket ── 文字版实例 /agent
                     ── UI_ACTION（翻到第几个槽、显示设置）──►
```

- 页面有 8 个文字槽，排成一个环。翻页只是本地换显示哪个槽，立即响应，不用等网络。
- 每翻一页上报新的槽号。服务记进度，把离得远的槽换成新的邻页，只发变了的字段。当前页前面留 4 页、后面留 3 页。
- 服务自己断好行，换行符写在文字里，这样每页行数是确定的。字宽是估的，拿不到眼镜的字体文件；行距是模拟器里量的，见 `LINE_PITCH`。
- 字号、粗细、亮度滑动时在页面里改，立刻生效，单击保存才上报。字号变了之后，断行要等服务重新分页，保存后约 2 秒才排好。
- 换字号时在当前页的第一个字处断页，这个字还在页首，它前面那一页可能不满。打开书时同样从上次的第一个字开始。
- 语音翻页、跳章、换字号时八个槽都要换，服务先发当前槽，其余放第二条：服务改不了页面正在显示哪个槽，只能改槽里的内容。
- 字号、粗细放在主数据里（`fs`、`fw`）：页面用 `dataSource://update` 写，服务的 UPDATE 也写这里，所以语音改字号、换书不用重开页面，自动翻页不会停。
- 进度条全页只有一条，宽度由服务随 UPDATE 发来，比翻页晚约 0.5 秒。放进每个槽的话，菜单移动和倒计时每写一次数据都要多刷 8 个绑定（`research.md` §10.2）。
- 和页图版共用进度和显示设置，换个 Skill 接着读。两边同时开着时，以最后翻页的那边为准。
- 页图版的字号 26、30 这边没有，打开时就近取一档，只要没在这边改字号，存回去的还是原来的值。粗细同理，没切换常规、粗体就不动页图版的六档。
- 平台约 120 秒没有业务消息就结束会话，所以每 90 秒重发一个不变的字段保活。30 分钟没操作就不再保活。真机上有会话在最后一次操作后撑了 292、394 秒，保活有效；页面关掉后保活不算数，会话约 120 秒后结束。

## 和页图版的差别

界面、菜单、自动翻页、亮度遮罩、书名图、进度条和页图版相同。

| 项 | 文字版 |
|---|---|
| 字号 | 16、18、20、22、24、28、32。原生字号只有固定档位，28、32 只有粗体 |
| 粗细 | 常规、粗体两档 |
| 亮度 | 遮罩分区：正文和书名每档遮 22，页眉页脚和两栏的小字每档遮 15，亮度 10% 时正文灰度约 51，章节名、页码、进度条、时间约 57。屏幕灰度低于约 30 不发光，再暗字就没了 |
| 行距 | 不能调。原生 `label` 没有行距属性；一行一个 `label` 会超过 128 个绑定，`a:for` 每行都算，隐藏的槽也算 |
| 两端对齐、缺字回退 | 没有，由眼镜的原生字体决定 |
| 卡死 | 翻页不下载图片，每秒写入不会打断加载。断流超过前面 4 页时，环会绕回去显示旧页 |

页面元素：根节点 61 个（上限 64），绑定 113 个（上限 128，超了内核直接丢属性）。模拟器日志的 `render ok ... bindings=` 就是这个数。

## 眼镜上的操作

| 操作 | 阅读时 | 菜单里 |
|---|---|---|
| 前滑 / 后滑 | 下一页 / 上一页 | 移动选中项，首尾相接 |
| 单击 | 打开菜单 | 返回阅读、自动翻页、下一章、上一章、显示设置、听书（听书时显示“暂停听书”） |
| 双击 | 底部提示“再双击一次退出”，再双击才退出 | 同左 |

第二次双击时页面上报 `exit`，服务结束会话（close 1000），麦克风才会关。提示是内核的 `confirm-back-text`，显示在 `prompt-config` 的位置，页面拿不到第一次双击，所以做不了自己的确认框。不能写 `forbidden="back"`：真机和模拟器都是双击完全没反应（内核日志 `Back key blocked by forbidden flag`），文档说仍会触发 `on-key-back`，也说 `confirm-back-text` 要配合它，都和实测相反。

语音能说：下一页、上一页、往后翻五页、下一章、上一章、跳到第三章、跳到百分之五十、回到开头、我看到哪了、书架上有什么书、字大一点、字小一点、打开《书名》、退出、能说什么。语音翻页后，自动翻页的倒计时最多晚一秒重置：服务端把 `v` 加一，页面每秒比对一次。

会话里麦克风一直开着，不用唤醒词（2026-10-31 真机日志）。所以超过 14 个字的话不当命令，听到别的话也不回应：播报会遮住页面。会跳走的命令（跳章、跳百分比、回到开头）要整句匹配：2026-11-01 用户跟别人说“记录一下当前开头的这个字符”，原来的写法把进度带回了书头。排查语音和镜腿事件看控制台的调试日志，每句话和每个 UI 操作都在里面。

## 听书

说“开始听书”或在菜单里选“听书”，服务从当前页读起，页面跟着翻。说“暂停”停下，说“继续听书”从刚才那句往前一点接着读；翻到别的页再继续，就从那一页读。

- 眼镜只能播平台的文字播报：`SPEAK` 只收纯文字，声音和语速改不了，第三方也发不了音频。
- 服务一个段落发一次，同一个 `speechId` 连续发，估计上一段读完才发下一段。平台不支持插入静音，换行也不停，段落之间的停顿就靠这个空隙，声音也借此和估算对齐一次。
- 正在读的段落，两格缩进换成“空格加 ●”。● 在原生字体里正好一个字宽，后面的字不动，也不会多折一行。从段落中间接着读时没有缩进，这一段不标。
- 平台没有播完回执，页面也读不到播报状态，读到哪是按语速估的（`LISTEN_CHARS_PER_SECOND`）。估得略慢更好：读完一段等一下，声音和估算就对齐了；估快了声音越落越远。真机上按 4.5 时每一两句停一下；按 5.5 时几句停约 1 秒、页面晚 4～5 秒，后来按用户量的两句算出约每秒 6.9 字（标点也算字，59 字 8.59 秒），现在用 6.6，段落之间再多算约 1 秒。页面比估算早 0.5 秒翻。进度只在翻页时保存。
- 读着的时候滑动翻页、语音翻页、跳章会从新位置接着读，改字号不打断，问进度这类要播报的命令会停下，别的话不接。
- 听书时不要开自动翻页：它每翻一页都算用户翻走，那一页会从头读。从菜单开始听书会自动关掉它，语音开始的关不了。

## 上线

云端：`deploy/cloud/README.md` 的「Agent 文字版实例」。WebSocket 地址 `wss://reader.example.com/text/agent`。

平台：

1. Agent 插件选「自定义接入」，认证选 Bearer Token，Token 和页图版 MCP 插件相同，通信方式选「ASR文本」。
2. 关联 Skill 的 `Pages` 里建页面 `reader-text`，内容用 `pages/reader-text/template.xml`，Mock 数据用 `data.json`，页面说明里写上 `reader-text`。
3. 在关联 Skill 里点真机测试，绑定眼镜。

不用发布就能测：2026-10-31 插件还是草稿时，平台连上了服务，`SESSION_INIT.pages` 里有这个页面，`description` 是 `reader-text`，也带 `dataSchema`。文档写发布后才下发，这里以真机结果为准。发布只影响没有绑定测试的设备。

## 还没验证的

- 平台会不会把 `svc://ui-action?mode=mcp` 转成 `UI_ACTION` 发过来。文档这样写，模拟器里页面确实发出了 `turn`、`display` 和槽号，但模拟器没有平台这一层。
- `font-size="{{fs}}"`、`font-weight="{{fw}}"` 和换行符在真机上的表现。
- 平台的 UPDATE 是只合并发来的字段，还是用它自己存的一份覆盖页面写过的 `fs`、`fw`。保存后服务会把新值发回去，所以两种情况都不会错。行数按量到的行距算：字号 16、18、20、22、24、28、32 每页 10、9、8、7、7、6、5 行。
- 平台生成的 `dataSchema` 和这里发的字段是否一致。
- 眼镜重启的原因。2026-10-31 和 11-01 两次都在开页面约 15 分钟时（15.0、14.7 分钟），都开着自动翻页，累计 8.5、9.3 分钟；服务端日志正常，平台日志只是翻页突然停了。还没有关着自动翻页连续开满 16 分钟的对照。
- 第一次双击的提示在真机上的位置和时长。模拟器里在屏幕底部中间，至少停 6 秒。
- 听书：实际语速、能连续读多久、会话会不会中途结束、播报时字幕会不会盖住页面、麦克风会不会把朗读声或周围的声音当成命令。
- 原生字体缺字：颜文字里的少见字符可能显示成方块。
- 固件要求：文档写 S1 固件 ≥ 1.11.5-RS-20260916.0354，控制台的设备页看不到固件版本。
