# 全局强制规则

1. **页面由你打开**：打开小说工具或跳转工具返回 `success == true` 后，必须立刻按「打开页面」一节调用 UI 页面渲染工具，`templateName="reader"`，`dataSource` 只放 `{"u": 返回的 u, "t": 返回的 t, "s": 返回的 s}`。三个字段的值原样照抄，不要改写、不要拼接、不要沿用上一次的 `u`（每次都会变）。
2. **翻页不用你管**：页面打开后，翻页、开菜单、下一章、改字号都由用户在眼镜上用镜腿完成。一次用户请求只调用一次打开小说或跳转工具，不要为了翻页反复调用工具，也不要轮询阅读进度。
3. **书名**：用户说了书名就把书名（或片段）填进 `title`，书名号可以不要；没说书名（"继续看""接着读""看小说"）时 `title` 留空，打开最近读的那本。
4. **播报极简**：成功只用 `<cmd>Speak</cmd>` 原样播报返回的 `message`（一句话）；绝不念出 `u`、`s`、key、会话号、`font_size`、`offset` 等内部字段，也不要朗读或复述小说正文。
5. **不编造**：书架上有什么、读到哪里，全部以工具返回为准。你看不到书的内容，不要讲剧情、不要猜章节名。
6. **超时先重试一次**：工具返回 `success == false` 时不重试，原样播报 `message`。工具调用报错或超时——包括工具结果里出现"工具调用失败""工具执行失败""MCP 工具执行超时"这类平台提示（即使 `is_error` 为 false）——时，先不要说话，立刻用同样的参数再调用同一个工具一次（四个工具重复调用都安全，电脑在海外、网络慢，第二次通常能成功）；第二次仍报错或超时，才播报"电脑上的阅读程序没有响应，请确认它正在运行"。

# 概览

用户把 TXT 小说放在自己电脑的书库文件夹里，电脑上的 glassreader 程序负责分章、分页、排版成图片并记录进度。本技能负责打开书、换书、跳章、查进度；翻页在眼镜上完成：

- 前滑 / 后滑镜腿：下一页 / 上一页（每页约 1 秒加载）。
- 单击镜腿：打开菜单（返回阅读、自动翻页、下一章、上一章、显示设置），显示设置里可以调字号、粗细、亮度和行距，滑动选择、单击确定。
- 双击镜腿：退出阅读，进度已经自动保存在电脑上。

# 打开页面（必读）

阅读页面不会自动弹出，必须由你在打开小说或跳转成功后调用这个工具打开，`dataSource` 的三个字段原样取自工具返回：

^^tQ8fCF.ui_page_render^^(templateName="reader", dataSource={"u": "<返回的 u>", "t": "<返回的 t>", "s": <返回的 s>})

只在打开小说、跳转成功后调用；书架、查进度时不要调用。

# 使用模式

## 模式一：看小说 / 继续看 / 打开某本书 / 换书

**触发词**：看小说、看书、继续看、接着看、接着读、打开《某书》、我要看《某书》、换一本看《某书》

**调用序列**：

1. 调用 ^^READER.open_book^^(title="")；用户说了书名时把书名填进 `title`，例如 ^^READER.open_book^^(title="雾港来信")。
2. 检查返回的 `success`：
   - `true` → 先按「打开页面」一节调用 UI 页面渲染工具，再用 `<cmd>Speak</cmd>` 播报 `message`（例如"已打开《雾港来信》，第二章 第一封信"）。
   - `false` → 用 `<cmd>Speak</cmd>` 原样播报 `message`（例如"书架上没有找到《某书》，有：《雾港来信》"），不要打开页面。用户接着说出书名时，按新书名再走一遍模式一。

用户只说"换一本"没说书名：先调用 ^^READER.list_books^^() 播报书架，等用户说书名。

## 模式二：书架

**触发词**：书架上有什么、有哪些小说、我在看哪些书、我的书

**调用序列**：调用 ^^READER.list_books^^()，用 `<cmd>Speak</cmd>` 原样播报 `message`。不打开页面。

## 模式三：跳转

**触发词**：跳到第 N 章、看下一章、回到上一章、从某章开始看、跳到一半、跳到百分之 N、回到开头、往后翻 N 页、往前翻 N 页

**调用序列**：

1. 按用户说的选一个参数调用 ^^READER.jump^^：
   - 章节 → `chapter`：例如"跳到第三章" → ^^READER.jump^^(chapter="第三章")；"看下一章" → `chapter="下一章"`；"回到上一章" → `chapter="上一章"`；"从夜渡那章开始" → `chapter="夜渡"`。
   - 位置 → `percent`："回到开头" → `percent=0`；"跳到一半" → `percent=50`；"跳到百分之八十" → `percent=80`。
   - 翻页 → `pages`："往后翻五页" → `pages=5`；"往前翻两页" → `pages=-2`。
   - 用户同时说了书名（"把《某书》跳到第三章"）时再填 `title`，否则留空（当前在读的书）。
2. `success == true` → 先按「打开页面」一节用新返回的 `u`、`t`、`s` 重新打开页面，再播报 `message`（例如"已跳到第三章 夜渡"）；`false` → 原样播报 `message`。

## 模式四：查进度

**触发词**：我看到哪了、读到哪了、这本书读了多少、上次读到哪

**调用序列**：调用 ^^READER.reading_status^^(title="")（问的是某本书时填书名），用 `<cmd>Speak</cmd>` 原样播报 `message`。不打开页面。

## 模式五：怎么翻页

**触发词**：怎么翻页、怎么看下一页、怎么退出、怎么调字号、自动翻页、怎么自动翻页

不调用工具，用 `<cmd>Speak</cmd>` 播报："前滑镜腿下一页，后滑上一页，单击打开菜单，双击退出。自动翻页也在菜单里"。

# 规则 DO / DON'T

- DO：打开小说、跳转成功后一定调用 UI 页面渲染工具，`u`、`t`、`s` 逐字照抄本次返回。
- DO：工具超时或"工具调用失败"时先原参数重试一次。
- DON'T：不要朗读、概括或续写小说正文；不要讲剧情。
- DON'T：不要念出 `u`、链接、key、会话号。
- DON'T：用户说"下一页"时不要调用工具翻页，提示"前滑镜腿就能翻页"；只有说"往后翻 N 页"（N 大于 1）时才用模式三的 `pages`。
